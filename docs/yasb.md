# 📊 توثيق شريط المهام YASB (Yet Another Status Bar)

شريط **YASB** هو شريط علوي خفيف الوزن ومخصص للغاية، مصمم بهوية بصريّة حادة وشديدة التباين (Sharp Obsidian Dark Theme).

---

## 🎨 النظام البصري (Design System)

- **شريط شفاف بالكامل**: الخلفية ذات شفافية كاملة (`transparent`) لدمج الشريط مع سطح المكتب بدون مساحات زائدة (`0px top gap`).
- **تصميم الحواف الحادة**: إلغاء الانحناءات (`border-radius: 0px !important`) على جميع الأزرار والـ Popups والـ Tooltips.
- **تباين عالي (Obsidian Dark)**: نصوص باللون الأبيض الفضي (`#f5f5f5`) على خلفية سوداء داكنة جداً (`rgba(14, 14, 14, 0.96)`) مع حدود مستطيلة دقيقة (`#2a2a2a`).

---

## 🧩 عناصر الشريط (Widgets)

1. **مساحات العمل (Workspaces)**:
   - **الشاشة الرئيسية النشطة**: أبيض ناصع مع خط عريض.
   - **الشاشة الثانوية النشطة**: رمادي مميز مع نص أبيض.
   - **مساحات العمل غير النشطة**: رمادي داكن شفاف.
2. **أدوات النظام المضافة والمحثة (System Widgets)**:
   - 🌐 **سرعة شبكة الإنترنت (Traffic)**: عرض سرعة التنزيل والرفع المباشرة (`⬇ Download  ⬆ Upload`).
   - 💻 **استهلاك المعالج (CPU)**: نسبة الاستهلاك الإجمالية + تردد المعالج الحالي (MHz).
   - 🎮 **كرت الشاشة (GPU)**: نسبة استهلاك كرت الشاشة + درجة الحرارة + استهلاك الـ VRAM المباشرة والمحددة (`mem_used / mem_total`).
   - 🧠 **الذاكرة العشوائية (RAM)**: نسبة الاستهلاك المئوية + الحجم المباشر بالجيجابايت المستهلكة من الإجمالي (`virtual_mem_percent% (used / total)`).
   - 🚫 **البطارية**: تم حذف وإلغاء أيقونة البطارية بالكامل.
   - 🔊 **الصوت والمايك والنوتيفيكيشنز والساعة**: قائمة الأدوات المعتادة مع خيارات التحكم.
