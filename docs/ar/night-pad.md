# Notepad: محرر نصوص احترافي وسريع بلوحة المفاتيح (Lightweight Text Editor)

محرر نصوص وبرمجة خفيف، سريع وبسيط، مصمم ومبني خصيصاً لبيئة **MyEnv** على نظام ويندوز لتوفير سرعة تشغيل وحفظ تشبه الطرفيات البرمجية بدون نوافذ بطيئة. يتميز بواجهة داكنة مريحة للعين، حواف مستقيمة (0px)، شريط قوائم كلاسيكي نظيف (`File`, `Edit`, `View`, `Tools`)، جاهزية فورية للكتابة عند الفتح، شريط حفظ سريع تفاعلي من لوحة المفاتيح، ودعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL).

---

## 🚀 أبرز الميزات والخصائص

- **جاهزية فورية للكتابة فور الفتح**: بمجرد فتح المحرر (في أقل من 20ms) ينتقل التركيز مباشرة وبشكل فوري لحقل الكتابة دون الحاجة للمس الفأرة.
- **شريط حفظ سريع تفاعلي عبر لوحة المفاتيح (`Ctrl + S` / `Ctrl + Shift + S` / `F2`)**:
  - شريط حفظ مدمج في النافذة مستوحى من سرعة الطرفيات (Terminal-style).
  - **إكمال تلقائي للمسارات (Tab Autocompletion)**: الضغط على `Tab` يكمل أسماء المجلدات والملفات تلقائياً أثناء الكتابة.
  - **أزرار واختصارات المسارات السريعة**: القفز السريع للمجلدات الشائعة بضغطة زر أو اختصار: `F1` (المجلد الحالي)، `F2` (المستندات Documents)، `F3` (سطح المكتب Desktop)، `F4` (مجلد MyEnv).
  - **إنشاء المجلدات تلقائياً**: إذا حددت مساراً داخل مجلد غير موجود يتم إنشاؤه فوراً أثناء الحفظ.
  - **خيار الحفظ التقليدي**: إمكانية فتح نافذة ويندوز الكلاسيكية عبر `Alt + B` أو `Ctrl + Alt + S`.
- **دعم متقدم وكامل للغة العربية (Arabic & RTL)**:
  - **التبديل بين اتجاه اليمين واليسار (`Ctrl + Shift + R`)**: تحويل اتجاه الكتابة من اليمين إلى اليسار (RTL) أو العكس فوراً.
  - **كشف ذكي وتلقائي للغة العربية**: التعرف التلقائي على النصوص العربية وضبط الاتجاه نحو اليمين.
  - **خطوط عربية واضحة وأنيقة**: دمج خطوط Cascadia Code مع Cairo و Segoe UI لتوفير قراءة واضحة للنصوص العربية وتشكيلاتها والرموز البرمجية.
  - **عداد كلمات دقيق للنصوص العربية والإنجليزية**: حساب دقيق للكلمات متعددة اللغات بالاعتماد على معايير Unicode.
- **شريط قوائم كلاسيكي واضح**: يتضمن خيارات منظمة ومباشرة: `File` و `Edit` و `View` و `Tools`.
- **دعم دقيق ومتقدم للغة بايثون واللغات البرمجية**:
  - **بايثون (Python 3)**: تلوين متكامل للكلمات المفتاحية، الدوال القياسية (`print`, `len`, `range`, `isinstance`...)، التوابع الخاصة (`__init__`, `__str__`...)، الدوال المزخرفة (`@decorator`)، النصوص المنسقة (f-strings)، والتوثيق المتعدد الأسطر (docstrings)، مع إزاحة ذكية تلقائية (Smart Indentation) عند الضغط على Enter بعد النقطتين `:`.
  - **أكثر من 20 لغة مدعومة**: Python, PowerShell, JavaScript, TypeScript, JSON, YAML, Markdown, C#, C/C++, HTML, XML, CSS, PHP, SQL, Batch/CMD, INI/Config, Java, Rust, Go.
- **بحث واستبدال متقدم (`Ctrl + F` / `Ctrl + H`)**: شريط بحث مدمج يدعم مطابقة حالة الأحرف، الكلمة بالكامل، والتعابير النمطية (Regex) مع عداد للنتائج.
- **أدوات المطورين الأساسية**: تنسيق وضغط ملفات JSON (`Ctrl + Shift + J`)، تشفير وفك تشفير Base64 و URL، تحويل حالة الأحرف (`Ctrl + Shift + U` / `Ctrl + U`)، ترتيب الأسطر، حذف الأسطر المكررة أو الفارغة، وإدراج التاريخ والوقت بضغطة زر (`F5`).
- **شريط مهام / حالة سفلي نظيف**: يعرض موضع المؤشر (`Ln`, `Col`)، اتجاه النص (`LTR` / `RTL`)، عداد الأسطر والكلمات والأحرف، نسبة التكبير (`100%`)، نوع نهايات الأسطر (`Windows CRLF` / `Unix LF`)، ترميز الملف (`UTF-8`)، واللغة الحالية.
- **تكامل شامل مع بيئة MyEnv**: اختصار مباشر في GlazeWM (`Alt + N`)، وأمر تشغيل فوري في الطرفية وموجه الأوامر (`np [file]` أو `nightpad`).

## ⚡ طرق تشغيل Notepad

| طريقة التشغيل | الاختصار / الأمر | الوصف |
|---|---|---|
| **اختصار GlazeWM** | `Alt + N` | تشغيل فوري وسريع من أي مكان في النظام |
| **طرفية PowerShell** | `np [file]` / `nightpad [file]` | فتح الملف المحدد أو فتح محرر فارغ |
| **موجه الأوامر (CMD)** | `np [file]` / `nightpad [file]` | فتح الملف المحدد أو فتح محرر فارغ |
| **مشغل التطبيقات** | `Alt + Shift + Q` -> كتابة `NightPad` | الوصول للمحرر عبر قائمة البحث السريع في MyEnv |
| **السحب والإفلات** | سحب أي ملف إلى نافذة Notepad | فتح الملف فوراً |

## ⌨️ جدول اختصارات لوحة المفاتيح

### إدارة الملفات والحفظ السريع
| الاختصار | الوظيفة |
|---|---|
| `Ctrl + N` | مستند جديد (New) |
| `Ctrl + O` | فتح ملف (Open) |
| `Ctrl + S` | حفظ الملف فوراً (يفتح شريط الحفظ السريع إذا كان المستند جديداً) |
| `Ctrl + Shift + S` / `F2` / `Alt + S` | فتح شريط الحفظ السريع مع الإكمال التلقائي واختصارات المجلدات |
| `Ctrl + Alt + S` | فتح نافذة ويندوز الكلاسيكية لحفظ الملف |
| `F1` / `F2` / `F3` / `F4` | القفز السريع للمجلد الحالي / المستندات / سطح المكتب / مجلد MyEnv |
| `Tab` | الإكمال التلقائي لأسماء المجلدات والملفات في شريط الحفظ |
| `Alt + F4` | إغلاق المحرر (مع التنبيه للحفظ إذا تم التعديل) |

### اللغة العربية واتجاه النص
| الاختصار | الوظيفة |
|---|---|
| `Ctrl + Shift + R` | التبديل بين اتجاه الكتابة من اليمين لليسار (RTL / عربي) واليسار لليمين (LTR) |
| النقر على `[LTR]` / `[RTL]` في شريط الحالة | تبديل اتجاه الكتابة وتنسيق الفقرات |

### التحرير والتنسيق
| الاختصار | الوظيفة |
|---|---|
| `Ctrl + Z` / `Ctrl + Y` | تراجع (Undo) / إعادة (Redo) |
| `Ctrl + X` / `Ctrl + C` / `Ctrl + V` | قص / نسخ / لصق |
| `Ctrl + A` | تحديد الكل (Select All) |
| `Ctrl + D` | تكرار السطر الحالي (Duplicate Line) |
| `Ctrl + Shift + K` | حذف السطر الحالي (Delete Line) |
| `Alt + ↑` / `Alt + ↓` | تحريك السطر لأعلى / لأسفل |
| `Ctrl + /` | تعليق/إلغاء تعليق السطر البرمجي |
| `Ctrl + Shift + J` | تنسيق وترتيب ملفات JSON |
| `Ctrl + Shift + U` / `Ctrl + U` | تحويل النص إلى أحرف كبيرة / صغيرة |
| `F5` | إدراج التاريخ والوقت الحالي |

### البحث والتنقل
| الاختصار | الوظيفة |
|---|---|
| `Ctrl + F` | فتح شريط البحث |
| `Ctrl + H` | فتح شريط البحث والاستبدال |
| `F3` / `Enter` | النتيجة التالية |
| `Shift + F3` | النتيجة السابقة |
| `Ctrl + G` | الانتقال إلى سطر محدد (Go to Line) |
| `Esc` | إغلاق شريط الحفظ السريع / البحث / الانتقال والعودة للمحرر |

### العرض والتكبير
| الاختصار | الوظيفة |
|---|---|
| `Alt + Z` | تفعيل / إلغاء التفاف الأسطر (Word Wrap) |
| `Ctrl + Shift + L` | إظهار / إخفاء أرقام الأسطر |
| `Ctrl + +` / `Ctrl + -` | تكبير / تصغير حجم الخط |
| `Ctrl + عجلة الفأرة` | تكبير / تصغير سلس لحجم الخط |
| `Ctrl + 0` | استعادة حجم الخط الافتراضي (100%) |
