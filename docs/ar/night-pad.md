# 🌙 NightPad: محرر نصوص وبرمجة احترافي بالوضع الليلي (Night Mode Editor)

محرر نصوص وبرمجة خفيف وفائق السرعة، مصمم ومبني خصيصاً لبيئة **MyEnv** على نظام ويندوز. يتميز بثيم ليلي ساحر (Obsidian Dark)، شريط جانبي لاستعراض مجلدات ومشاريع العمل (Sidebar File Explorer)، محرك حفظ تلقائي ذكي (Auto-Save)، ودعم عميق للغات مثل بايثون (Python 3).

---

## 🚀 أبرز الميزات والخصائص

- **ثيم ليلي داكن واحترافي (Obsidian Night Mode)**: خلفية داكنة عميقة (`#0d1117`)، أسطح أنيقة (`#161b22`)، نصوص عالية التباين (`#f0f6fc`)، ولمسات زرقاء ساطعة (`#58a6ff`) مع تصميم حاد مستقيم خالٍ من الحواف الدائرية (0px).
- **شريط جانبي لاستعراض الملفات والمجلدات (`Ctrl + B`)**: شجرة تصفح هرمية سريعة تعرض كافة مجلدات وملفات المشروع أو المسار الحالي. يمكنك الضغط المزدوج أو الضغط على Enter لفتح أي ملف في تبويب جديد.
- **الحفظ التلقائي الذكي (`Ctrl + Shift + A`)**: محرك حفظ يعمل في الخلفية كل 3 ثوانٍ لحفظ التعديلات في الملفات المفتوحة دون أي مقاطعة لعملك، مع مؤشر لحالة الحفظ (`💾 Auto-Save: ON/OFF`).
- **دعم متقدم للغة بايثون واللغات البرمجية**:
  - **بايثون (Python 3)**: تلوين كامل للكلمات المفتاحية، الدوال القياسية (`print`, `len`, `range`, `isinstance`...)، التوابع الخاصة (`__init__`, `__str__`...)، الدوال المزخرفة (`@decorator`)، النصوص المنسقة (f-strings)، والتوثيق المتعدد الأسطر (docstrings)، مع إزاحة ذكية تلقائية (Smart Indentation) عند الضغط على Enter بعد النقطتين `:`.
  - **أكثر من 20 لغة مدعومة**: PowerShell, JavaScript, TypeScript, JSON, YAML, Markdown, C#, C/C++, HTML, XML, CSS, PHP, SQL, Batch/CMD, INI/Config, Java, Rust, Go.
- **نظام التبويبات المتعددة (Multi-Tabs)**: فتح ملفات متعددة بسهولة، دعم السحب والإفلات (Drag & Drop)، مؤشر التعديل غير المحفوظ (`*`)، وإغلاق التبويبات بالزر الأوسط للفأرة.
- **المعاينة الحية لملفات الماركداون (`Ctrl + Shift + M`)**: شاشة منقسمة لعرض النصوص المنسقة، العناوين، الأكواد البرمجية، والقوائم بشكل مباشر أثناء الكتابة.
- **بحث واستبدال متقدم (`Ctrl + F` / `Ctrl + H`)**: دعم التعابير النمطية (Regex)، مطابقة حالة الأحرف، مطابقة الكلمة بالكامل، وعدّاد مباشر للمطابقات.
- **مجموعة أدوات المطورين الذكية**: تنسيق وترتيب ملفات JSON (`Ctrl + Shift + J`)، تشفير وفك تشفير Base64 و URL، تحويل حالة الأحرف، ترتيب الأسطر، حذف التكرار، وإدراج التاريخ والوقت بضغطة زر (`F5`).
- **تكامل شامل مع البيئة**: اختصار مخصص في GlazeWM (`Alt + N`)، أوامر سريعة في الطرفية (`np`, `nightpad`, `notepad`)، وتوافق تام مع نظام النوافذ التلقائي (Tiling).

## ⚡ طرق تشغيل NightPad

| طريقة التشغيل | الاختصار / الأمر | الوصف |
|---|---|---|
| **اختصار GlazeWM** | `Alt + N` | تشغيل فوري وسريع من أي مكان في النظام |
| **طرفية PowerShell** | `np [file or folder]` | فتح الملف أو مجلد المشروع الحالي في الشريط الجانبي |
| **موجه الأوامر (CMD)** | `np [file or folder]` | فتح الملف أو مجلد المشروع الحالي في الشريط الجانبي |
| **مشغل التطبيقات** | `Alt + Shift + Q` -> كتابة `NightPad` | الوصول للمحرر عبر قائمة البحث السريع في MyEnv |
| **السحب والإفلات** | سحب أي ملف أو مجلد إلى نافذة NightPad | فتح الملفات فوراً في تبويبات جديدة أو فتح مجلد العمل |

## ⌨️ جدول اختصارات لوحة المفاتيح

### إدارة الملفات ومجلدات العمل
| الاختصار | الوظيفة |
|---|---|
| `Ctrl + N` | فتح تبويب مستند فارغ جديد |
| `Ctrl + O` | فتح نافذة اختيار ملف |
| `Ctrl + Shift + O` | فتح مجلد عمل / مشروع جديد (Open Folder) |
| `Ctrl + S` | حفظ المستند الحالي |
| `Ctrl + Shift + S` | حفظ باسم (Save As) |
| `Ctrl + Alt + S` | حفظ جميع الملفات المفتوحة |
| `Ctrl + Shift + A` | تفعيل / إلغاء الحفظ التلقائي (Toggle Auto-Save) |
| `Ctrl + W` | إغلاق التبويب النشط |
| `Alt + F4` | إغلاق المحرر (مع التنبيه لحفظ التعديلات) |

### الشريط الجانبي والعرض
| الاختصار | الوظيفة |
|---|---|
| `Ctrl + B` | إظهار / إخفاء الشريط الجانبي للملفات (Toggle Sidebar) |
| `Alt + Z` | تفعيل / إلغاء التفاف الأسطر (Word Wrap) |
| `Ctrl + Shift + M` | تفعيل شاشة المعاينة الحية لملفات Markdown |
| `Ctrl + Shift + L` | إظهار / إخفاء أرقام الأسطر |
| `Ctrl + +` / `Ctrl + -` | تكبير / تصغير حجم الخط |
| `Ctrl + عجلة الفأرة` | تكبير / تصغير سلس لحجم الخط |
| `Ctrl + 0` | استعادة حجم الخط الافتراضي (100%) |

### التحرير والتنقل
| الاختصار | الوظيفة |
|---|---|
| `Ctrl + Z` / `Ctrl + Y` | تراجع (Undo) / إعادة (Redo) |
| `Ctrl + D` | تكرار السطر الحالي (Duplicate Line) |
| `Ctrl + Shift + K` | حذف السطر الحالي (Delete Line) |
| `Alt + ↑` / `Alt + ↓` | تحريك السطر الحالي لأعلى / لأسفل |
| `Ctrl + /` | تعليق/إلغاء تعليق السطر البرمجي |
| `Ctrl + Shift + J` | تنسيق وترتيب ملفات JSON (Format JSON) |
| `Ctrl + Shift + U` / `Ctrl + U` | تحويل النص إلى أحرف كبيرة / صغيرة |
| `F5` | إدراج التاريخ والوقت الحالي |
| `Ctrl + G` | الانتقال إلى سطر محدد (Go to Line) |

### البحث والاستبدال
| الاختصار | الوظيفة |
|---|---|
| `Ctrl + F` | فتح شريط البحث |
| `Ctrl + H` | فتح شريط البحث والاستبدال |
| `F3` / `Enter` | الانتقال للنتيجة التالية |
| `Shift + F3` | الانتقال للنتيجة السابقة |
| `Alt + R` | استبدال النتيجة الحالية |
| `Alt + A` | استبدال جميع النتائج |
| `Esc` | إغلاق شريط البحث أو الانتقال |

## 🛠️ هيكلية الملفات والشفرة المصدرية

- **الشفرة المصدرية**: [`tools/nightpad/`](file:///%USERPROFILE%/Documents/myenv/tools/nightpad)
  - `MainWindow.xaml` & `MainWindow.xaml.cs`: الواجهة الرسومية، الشريط الجانبي للملفات، وإدارة التحرير.
  - `Models/FileNode.cs`: نموذج شجرة الملفات والمجلدات للشريط الجانبي.
  - `Models/EditorDocument.cs`: نموذج إدارة بيانات المستند وإحصائيات الكلمات والأسطر.
  - `Services/SyntaxService.cs`: تعريفات تلوين اللغات البرمجية وقواعد لغة بايثون XSHD.
  - `Services/TextTransformService.cs`: دوال التنسيق والتحويل والتشفير المتقدمة.
- **الملف التنفيذي النهائي**: [`scripts/nightpad/NightPad.exe`](file:///%USERPROFILE%/Documents/myenv/scripts/nightpad/NightPad.exe)
