# Notepad: محرر نصوص احترافي وبسيط (Lightweight Text Editor)

محرر نصوص وبرمجة خفيف، سريع وبسيط، مصمم ومبني خصيصاً لبيئة **MyEnv** على نظام ويندوز. يتميز بواجهة داكنة مريحة للعين، حواف مستقيمة (0px)، شريط قوائم كلاسيكي نظيف (`File`, `Edit`, `View`, `Tools`)، شريط حالة سفلي، ودعم ممتاز لتلوين الأكواد البرمجية للغات مثل بايثون وغيرها.

---

## 🚀 أبرز الميزات والخصائص

- **واجهة بسيطة وغير معقدة**: انعدام أي تعقيدات أو عناصر مشتتة، تشغيل فوري بأقل من 20 مللي ثانية، وخلو تام من الأشرطة الجانبية المزعجة أو الأيقونات التعبيرية غير المناسبة.
- **شريط قوائم كلاسيكي واضح**: يتضمن خيارات منظمة ومباشرة: `File` و `Edit` و `View` و `Tools`.
- **دعم دقيق ومتقدم للغة بايثون واللغات البرمجية**:
  - **بايثون (Python 3)**: تلوين متكامل للكلمات المفتاحية، الدوال القياسية (`print`, `len`, `range`, `isinstance`...)، التوابع الخاصة (`__init__`, `__str__`...)، الدوال المزخرفة (`@decorator`)، النصوص المنسقة (f-strings)، والتوثيق المتعدد الأسطر (docstrings)، مع إزاحة ذكية تلقائية (Smart Indentation) عند الضغط على Enter بعد النقطتين `:`.
  - **أكثر من 20 لغة مدعومة**: Python, PowerShell, JavaScript, TypeScript, JSON, YAML, Markdown, C#, C/C++, HTML, XML, CSS, PHP, SQL, Batch/CMD, INI/Config, Java, Rust, Go.
- **بحث واستبدال متقدم (`Ctrl + F` / `Ctrl + H`)**: شريط بحث مدمج يدعم مطابقة حالة الأحرف، الكلمة بالكامل، والتعابير النمطية (Regex) مع عداد للنتائج.
- **أدوات المطورين الأساسية**: تنسيق وضغط ملفات JSON (`Ctrl + Shift + J`)، تشفير وفك تشفير Base64 و URL، تحويل حالة الأحرف (`Ctrl + Shift + U` / `Ctrl + U`)، ترتيب الأسطر، حذف الأسطر المكررة أو الفارغة، وإدراج التاريخ والوقت بضغطة زر (`F5`).
- **شريط مهام / حالة سفلي نظيف**: يعرض موضع المؤشر (`Ln`, `Col`)، عداد الأسطر والكلمات والأحرف، نسبة التكبير (`100%`)، نوع نهايات الأسطر (`Windows CRLF` / `Unix LF`)، ترميز الملف (`UTF-8`)، واللغة الحالية.
- **تكامل شامل مع بيئة MyEnv**: اختصار مباشر في GlazeWM (`Alt + N`)، وأمر تشغيل فوري في الطرفية وموجه الأوامر (`np [file]` أو `nightpad`).

## ⚡ طرق تشغيل Notepad

| طريقة التشغيل | الاختصار / الأمر | الوصف |
|---|---|---|
| **اختصار GlazeWM** | `Alt + N` | تشغيل فوري وسريع من أي مكان في النظام |
| **طرفية PowerShell** | `np [file]` / `nightpad [file]` | فتح الملف المحدد أو فتح محرر فارغ |
| **موجه الأوامر (CMD)** | `np [file]` / `nightpad [file]` | فتح الملف المحدد أو فتح محرر فارغ |
| **مشغل التطبيقات** | `Alt + Shift + Q` -> كتابة `NightPad` | الوصول للمحرر عبر قائمة البحث السريع في MyEnv |
| **السحب والإفلات** | سحب أي ملف إلى نافذة Notepad | فتح الملف فوراً |

## ⌨️ جدول اختصارات لوحة المفاتيح

### إدارة الملفات
| الاختصار | الوظيفة |
|---|---|
| `Ctrl + N` | مستند جديد (New) |
| `Ctrl + O` | فتح ملف (Open) |
| `Ctrl + S` | حفظ الملف (Save) |
| `Ctrl + Shift + S` | حفظ باسم (Save As) |
| `Alt + F4` | إغلاق المحرر (مع التنبيه للحفظ إذا تم التعديل) |

### التحرير والتنسيق
| الاختصار | الوظيفة |
|---|---|
| `Ctrl + Z` / `Ctrl + Y` | تراجع (Undo) / إعادة (Redo) |
| `Ctrl + X` / `Ctrl + C` / `Ctrl + V` | قص / نسخ / لصق |
| `Ctrl + A` | تحديد الكل (Select All) |
| `Ctrl + D` | تكرار السطر الحالي (Duplicate Line) |
| `Ctrl + Shift + K` | حذف السطر الحالي (Delete Line) |
| `Alt + ↑` / `Alt + ↓` | تحريك السطر لأعلى / لأسفل |
| `Ctrl + /` | تعليق/إلغاء تعليق السطر البرمجي |
| `Ctrl + Shift + J` | تنسيق وترتيب ملفات JSON |
| `Ctrl + Shift + U` / `Ctrl + U` | تحويل النص إلى أحرف كبيرة / صغيرة |
| `F5` | إدراج التاريخ والوقت الحالي |

### البحث والتنقل
| الاختصار | الوظيفة |
|---|---|
| `Ctrl + F` | فتح شريط البحث |
| `Ctrl + H` | فتح شريط البحث والاستبدال |
| `F3` / `Enter` | النتيجة التالية |
| `Shift + F3` | النتيجة السابقة |
| `Ctrl + G` | الانتقال إلى سطر محدد (Go to Line) |
| `Esc` | إغلاق شريط البحث |

### العرض والتكبير
| الاختصار | الوظيفة |
|---|---|
| `Alt + Z` | تفعيل / إلغاء التفاف الأسطر (Word Wrap) |
| `Ctrl + Shift + L` | إظهار / إخفاء أرقام الأسطر |
| `Ctrl + +` / `Ctrl + -` | تكبير / تصغير حجم الخط |
| `Ctrl + عجلة الفأرة` | تكبير / تصغير سلس لحجم الخط |
| `Ctrl + 0` | استعادة حجم الخط الافتراضي (100%) |
