# 🌙 NightPad: محرر نصوص احترافي بالوضع الليلي (Night Mode Text Editor)

محرر نصوص وبرمجة خفيف وفائق السرعة، مصمم ومبني خصيصاً لبيئة **MyEnv** على نظام ويندوز. يتميز بثيم ليلي ساحر (Obsidian Dark)، حواف مستقيمة حادة (0px)، واستجابة فورية دون أي تأخير.

---

## 🚀 أبرز الميزات والخصائص

- **ثيم ليلي داكن واحترافي (Obsidian Night Mode)**: خلفية داكنة عميقة (`#0d1117`)، نصوص عالية التباين (`#f0f6fc`)، ولمسات زرقاء ساطعة (`#58a6ff`) مع تصميم حاد مستقيم خالٍ من الحواف الدائرية.
- **نظام التبويبات المتعددة (Multi-Tabs)**: فتح ملفات متعددة بسهولة، دعم السحب والإفلات (Drag & Drop)، مؤشر التعديل غير المحفوظ (`*`)، وإغلاق التبويبات بالزر الأوسط للفأرة.
- **تلوين الأكواد لأكثر من 20 لغة برمجة (Syntax Highlighting)**: دعم تلقائي وفوري للغات: PowerShell, Python, JSON, YAML, Markdown, C#, C/C++, JavaScript, TypeScript, HTML, XML, CSS, PHP, SQL, Batch/CMD, INI/Config, Java, Rust, Go.
- **المعاينة الحية لملفات الماركداون (`Ctrl + Shift + M`)**: شاشة منقسمة لعرض النصوص المنسقة، العناوين، الأكواد البرمجية، والقوائم بشكل مباشر أثناء الكتابة.
- **بحث واستبدال متقدم (`Ctrl + F` / `Ctrl + H`)**: دعم التعابير النمطية (Regex)، مطابقة حالة الأحرف، مطابقة الكلمة بالكامل، وعدّاد مباشر للمطابقات.
- **مجموعة أدوات المطورين الذكية**: تنسيق وضغط ملفات JSON، تشفير وفك تشفير Base64 و URL، تحويل حالة الأحرف، ترتيب الأسطر، وحذف التكرار، وإدراج التاريخ والوقت بضغطة زر.
- **تكامل شامل مع البيئة**: اختصار مخصص في GlazeWM (`Alt + N`)، أوامر سريعة في الطرفية (`np`, `nightpad`, `notepad`)، وتوافق تام مع نظام النوافذ التلقائي (Tiling).

## ⚡ طرق تشغيل NightPad

| طريقة التشغيل | الاختصار / الأمر | الوصف |
|---|---|---|
| **اختصار GlazeWM** | `Alt + N` | تشغيل فوري وسريع من أي مكان في النظام |
| **طرفية PowerShell** | `np [file]` / `nightpad [file]` | فتح الملف المحدد أو مستند جديد مباشرة من PowerShell |
| **موجه الأوامر (CMD)** | `np [file]` / `nightpad [file]` | فتح الملف المحدد أو مستند جديد مباشرة من CMD |
| **مشغل التطبيقات** | `Alt + Shift + Q` -> كتابة `NightPad` | الوصول للمحرر عبر قائمة البحث السريع في MyEnv |
| **السحب والإفلات** | سحب أي ملف إلى نافذة NightPad | فتح الملفات فوراً في تبويبات جديدة |

## ⌨️ جدول اختصارات لوحة المفاتيح

### إدارة الملفات
| الاختصار | الوظيفة |
|---|---|
| `Ctrl + N` | فتح تبويب مستند فارغ جديد |
| `Ctrl + O` | فتح نافذة اختيار ملف |
| `Ctrl + S` | حفظ المستند الحالي |
| `Ctrl + Shift + S` | حفظ باسم (Save As) |
| `Ctrl + Alt + S` | حفظ جميع الملفات المفتوحة |
| `Ctrl + W` | إغلاق التبويب النشط |
| `Alt + F4` | إغلاق المحرر (مع التنبيه لحفظ التعديلات) |

### التحرير والتنقل
| الاختصار | الوظيفة |
|---|---|
| `Ctrl + Z` / `Ctrl + Y` | تراجع (Undo) / إعادة (Redo) |
| `Ctrl + D` | تكرار السطر الحالي (Duplicate Line) |
| `Ctrl + Shift + K` | حذف السطر الحالي (Delete Line) |
| `Alt + ↑` / `Alt + ↓` | تحريك السطر الحالي لأعلى / لأسفل |
| `Ctrl + /` | تعليق/إلغاء تعليق السطر البرمجي |
| `F5` | إدراج التاريخ والوقت الحالي |
| `Ctrl + G` | الانتقال إلى سطر محدد (Go to Line) |

### البحث والاستبدال
| الاختصار | الوظيفة |
|---|---|
| `Ctrl + F` | فتح شريط البحث |
| `Ctrl + H` | فتح شريط البحث والاستبدال |
| `F3` / `Enter` | الانتقال للنتيجة التالية |
| `Shift + F3` | الانتقال للنتيجة السابقة |
| `Alt + R` | استبدال النتيجة الحالية |
| `Alt + A` | استبدال جميع النتائج |
| `Esc` | إغلاق شريط البحث أو الانتقال |

### العرض وأدوات المطورين
| الاختصار | الوظيفة |
|---|---|
| `Alt + Z` | تفعيل / إلغاء التفاف الأسطر (Word Wrap) |
| `Ctrl + Shift + M` | تفعيل شاشة المعاينة الحية لملفات Markdown |
| `Ctrl + Shift + L` | إظهار / إخفاء أرقام الأسطر |
| `Ctrl + Shift + J` | تنسيق وترتيب ملفات JSON (Format JSON) |
| `Ctrl + Shift + U` | تحويل النص إلى أحرف كبيرة (UPPERCASE) |
| `Ctrl + U` | تحويل النص إلى أحرف صغيرة (lowercase) |
| `Ctrl + +` / `Ctrl + -` | تكبير / تصغير حجم الخط |
| `Ctrl + عجلة الفأرة` | تكبير / تصغير سلس لحجم الخط |
| `Ctrl + 0` | استعادة حجم الخط الافتراضي (100%) |
| `F1` | عرض قائمة الاختصارات السريعة |

## 🛠️ هيكلية الملفات والشفرة المصدرية

- **الشفرة المصدرية**: [`tools/nightpad/`](file:///%USERPROFILE%/Documents/myenv/tools/nightpad)
