# 🤖 إعدادات وتكامل بيئة Gemini Antigravity

دليل الإعداد المركزي وتكامل موجه التعليمات والقواعد والمهارات وخوادم بروتوكول سياق النموذج (MCP) لـ **Google Antigravity (AGY)** داخل بيئة MyEnv.

---

## 📂 بنية الوصلة المجلدية (Directory Junction)

لضمان حفظ جميع تعليمات المساعد الذكي وإعدادات أدواته ومهاراته بشكل دائم داخل نظام التحكم بالإصدارات Git واستعادتها تلقائياً على أي جهاز، يتم ربط مجلد الإعدادات عبر وصلة مجلدية NTFS:

| مسار النظام (المصدر) | مسار المستودع داخل MyEnv (الهدف) | الغرض |
|---|---|---|
| `%USERPROFILE%\.gemini\config` | [`gemini/`](file:///%USERPROFILE%/Documents/myenv/gemini) | مجلد الإعدادات العامة الشامل لـ Antigravity |

---

## 🛠️ الملفات والهيكل التنظيمي

```
myenv/
└── gemini/
    ├── README.md               # نظرة عامة وتفاصيل الهيكل
    ├── GEMINI.md               # التعليمات العامة، معايير الشيفرة، وإرشادات Git
    ├── mcp_config.json         # إعدادات خوادم بروتوكول سياق النموذج (MCP)
    ├── rules/                  # مجلد القواعد التفصيلية والسياقية (*.md)
    │   └── README.md
    └── skills/                 # المهارات المخصصة بحسب الطلب (* / SKILL.md)
        └── README.md
```

### 1. ملف `GEMINI.md` (التعليمات العامة)
يحتوي على القواعد الإلزامية التي يطبقها المساعد تلقائياً في كل من **Antigravity CLI (agy)** و **Antigravity IDE**:
- **مطابقة لغة المحادثة**: الرد التلقائي بنفس لغة المستخدم.
- **معايير وهيكلة المجلدات**: تقسيم الملفات الكبيرة إلى ملفات فرعية صغيرة، ووجود ملف `README.md` يوضح وظيفة كل ملف في المجلد.
- **سير عمل Git**: استخدام صيغة Conventional Commits والاعتماد الدائم على الفرع الرئيسي `main`.
- **ضوابط الأمان**: منع الأوامر التدميرية وحماية المفاتيح السرية والرموز الخاصة.

### 2. ملف `mcp_config.json` (بروتوكول سياق النموذج)
لربط وتوسيع قدرات المساعد البرمجي بخوادم MCP خارجية للتعامل مع قواعد البيانات وأدوات النظام.

---

## 🚀 التثبيت والتهيئة التلقائية

لإنشاء أو تفعيل الربط المجلدي التلقائي في أي وقت:
```powershell
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\Documents\myenv\scripts\setup-gemini-config.ps1"
```

أو عبر تشغيل السكربت الشامل لإعداد البيئة:
```powershell
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\Documents\myenv\scripts\setup-all.ps1"
```
