# 🌐 توثيق أداة التحكم في الشبكة NetLimiter

أداة إدارية متكاملة ومستقرة للتحكم في استهلاك حركة البيانات عبر الشبكة (Bandwidth Limiter) وتحديد حد إستهلاك الأقصى للتحميل والرفع لكل برنامج على حدة في Windows.

---

## 🚀 المميزات الرئيسية لـ NetLimiter في البيئة (`myenv`)

| الميزة | الوصف |
|---|---|
| ⚡ **تحديد الحد الأقصى للسرعة** | تحديد سقف لسرعة التحميل (**DL Limit**) والرفع (**UL Limit**) لكل عملية أو تطبيق (`chrome.exe`, `steam.exe`, إلخ). |
| 🛡️ **استقرار كامل للنظام** | تعمل كـ Windows Service خفيفة بالخلفية بدون استهلاك للموارد أو مشاكل في الاتصال. |
| 🪟 **التكامل مع GlazeWM** | تم ضبط قواعد النافذة في `glazewm/config.yaml` لتفتح الواجهة تلقائياً في النمط العائم المتمركز (**Floating Centered**). |
| 📦 **إدارة عبر WinGet** | تم إدراج الحزمة `LocktimeSoftware.NetLimiter` ضمن ملف `winget-packages.json` لاستعادتها تلقائياً. |

---

## ⚙️ طريقة الاستخدام وتحديد السرعة (Quick Guide)

1. **تشغيل البرنامج**:
   افتح قائمة البحث (`Alt + Q`) واكتب `NetLimiter` واضغط `Enter`.
2. **تطبيق حد استهلاك على تطبيق معين**:
   * ابحث عن التطبيق في القائمة الرئيسية (مثل `Chrome` أو `Steam` أو `IDM`).
   * انقر في خانة **DL Limit** (حد التحميل) أو **UL Limit** (حد الرفع).
   * ضع علامة صح `[✓]` لتفعيل الحد، ثم أدخل السرعة المطلوبة (مثلاً: `2 MB/s` أو `500 KB/s`).
3. **تطبيق قواعد التكتم أو الأولويات**:
   * يمكنك إعطاء أولوية مرتفعة لبرامج العمل/التطوير وتخفيض أولوية التحديثات بالخلفية.

---

## 🛠️ التثبيت والصيانة عبر PowerShell

إعادة تثبيت أو استعادة NetLimiter عبر سكريبت البيئة:
```powershell
winget install --id LocktimeSoftware.NetLimiter --source winget
```
