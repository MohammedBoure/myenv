# 🪟 توثيق مدير النوافذ GlazeWM

**GlazeWM** هو مدير نوافذ مقسمة (Tiling Window Manager) لنظام Windows يتيح التحكم بالكامل بالنوافذ عبر لوحة المفاتيح.

---

## 📂 ملف التهيأة

- **ملف الإعدادات الرئيسي**: [glazewm/config.yaml](file:///%USERPROFILE%/Documents/myenv/glazewm/config.yaml)

---

## ⌨️ جدول اختصارات لوحة المفاتيح الكامل

### 🎯 التنقل وتحديد التركيز
| الاختصار | الوظيفة |
|---|---|
| `Alt + H` / `Alt + ←` | نقل التركيز للنافذة اليسرى |
| `Alt + L` / `Alt + →` | نقل التركيز للنافذة اليمنى |
| `Alt + K` / `Alt + ↑` | نقل التركيز للنافذة العلوية |
| `Alt + J` / `Alt + ↓` | نقل التركيز للنافذة السفلية |
| `Alt + Shift + H/L/K/J` | تحريك النافذة الحالية في الاتجاه المحدد |
| `Alt + Space` / `Alt + W` | التبديل بين حالات النافذة والتركيز |
| `Alt + Shift + P` | التوقف المؤقت لـ GlazeWM والعودة لسلوك الويندوز |
| `Alt + Shift + Space` | تحويل النافذة إلى عائمة وموسّطة (Floating) |
| `Alt + T` | إعادة النافذة لحالة التقسيم (Tiling) |
| `Alt + F` | تبديل وضع ملء الشاشة (Fullscreen) |
| `Alt + M` | تصغير النافذة (Minimize) |
| `Alt + Q` | إغلاق النافذة الحالية (Close Window) |

---

### 📐 اتجاهات التقسيم وتغيير الأحجام
| الاختصار | الوظيفة |
|---|---|
| **التقسيم الذكي التلقائي** | تقسيم تلقائي (أفقي للعرَض، عمودي للارتفاع) |
| `Alt + V` | تبديل اتجاه التقسيم (أفقي <-> عمودي) |
| `Alt + Shift + V` | تقسيم عمودي إجباري (أسفل النافذة الحالية) |
| `Alt + Ctrl + V` | تقسيم أفقي إجباري (بجانب النافذة الحالية) |
| `Alt + U` / `Alt + P` | تصغير / زيادة عرض النافذة بمقدار 2% |
| `Alt + I` / `Alt + O` | تصغير / زيادة ارتفاع النافذة بمقدار 2% |
| `Alt + R` | وضع التكبير والتصغير التفاعلي (`Esc` للخروج) |

---

### 🖥️ مساحات العمل والتنقل بين الشاشات
* **الشاشة اليسرى `DISPLAY1`**: مساحات العمل من `1` إلى `8`.
* **الشاشة اليمنى `DISPLAY8`**: مساحات العمل من `9` إلى `10`.

| الاختصار | الوظيفة |
|---|---|
| `Alt + 1..8` | الانتقال لمساحات العمل 1-8 (الشاشة اليسرى) |
| `Alt + 9..0` | الانتقال لمساحات العمل 9-10 (الشاشة اليمنى) |
| `Alt + Shift + 1..0` | نقل النافذة الحالية لمساحة العمل والذهاب إليها |
| `Alt + PageUp` / `Alt + A` | الانتقال لمساحة العمل النشطة السابقة |
| `Alt + PageDown` / `Alt + S` | الانتقال لمساحة العمل النشطة التالية |
| `Alt + D` | الانتقال لآخر مساحة عمل تم استخدامها |
| `Alt + Shift + A/F/D/S` | نقل مساحة العمل للشاشة (يسار/يمين/أعلى/أسفل) |

---

### 🚀 تشغيل البرامج والتحكم
| الاختصار | الوظيفة |
|---|---|
| `Alt + Shift + Q` | تشغيل مشغل التطبيقات السريع (`app-launcher.ps1`) |
| `Win + Shift + C` / `Alt + Shift + C` | ترجمة النص المحدد فوراً (نسخ تلقائي `Ctrl+C`) |
| `Win + Shift + Q` / `Alt + Shift + T` | ترجمة منطقة الشاشة عبر OCR (تظليل صورة) |
| `Alt + Shift + S` | التقاط كامل الشاشة والحفظ المباشر للحافظة وللملفات |
| `Alt + Shift + X` | فتح مدير المهام الفوري (Task Manager) |
| `Alt + Shift + M` | كتم/تفعيل صوت الجهاز المباشر |
| `Alt + Shift + Z` | تبديل شفافية النافذة النشطة 80% / 100% |
| `Alt + Enter` | فتح نافذة `cmd.exe` في مسار متصفح الملفات الحالي |
| `Alt + Ctrl + Enter` | فتح نافذة `powershell.exe` في مسار Explorer |
| `Alt + Shift + R` | إعادة تحميل إعدادات GlazeWM |
| `Alt + Shift + E` | الخروج الآمن من GlazeWM |
