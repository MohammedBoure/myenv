# 🌳 دليل أداة شجرة وتفاصيل المشروع len (ProjectLens)

أداة **len (ProjectLens)** هي أداة سريعة وخفيفة لسطر الأوامر مخصصة لعرض شجرة المجلدات بشكل منسق ونظيف، مع إمكانية إدارة قائمة العناصر المحظورة وحفظها دائمياً، والتحكم بعمق الاستعراض، واستخراج إحصائيات الأكواد، ونسخ الشجرة مباشرة للحافظة (Clipboard).

---

## 🚀 الميزات الرئيسية

- 🌳 **عرض شجرة المجلدات**: إظهار الهيكل التنظيمي للمشاريع بأسلوب شجري واضح وسريع.
- 🔢 **التحكم بعمق الاستعراض (Depth)**: تحديد مستوى عمق المجلدات المطلوب (مثل `len 3` أو `len ./src 2`).
- 🚫 **إدارة قائمة الحظر الدائمة (Blocklist)**:
  - إضافة ملفات محظورة: `len -f [file_name_or_pattern]`
  - إضافة مجلدات محظورة: `len -F [folder_name_or_pattern]`
  - إزالة ملفات من الحظر: `len -rf [file_name_or_pattern]`
  - إزالة مجلدات من الحظر: `len -rF [folder_name_or_pattern]`
  - استعراض العناصر المحظورة: `len -l` أو `len --list-blocked`
- 📋 **نسخ النتيجة للحافظة (`-c`)**: نسخ شجرة المجلدات بضغطة زر لمشاركتها مع نماذج الذكاء الاصطناعي أو التوثيق.
- 📊 **إحصائيات الملفات والأكواد (`-s`, `-e`)**: عرض عدد أسطر الكود، وأحجام الملفات، ونسبة التغطية وتوثيق المشروع.
- 🔄 **تثبيت وتحديث تلقائي من المستودع البعيد**: تدار وتحدث تلقائياً عبر سكريبت `scripts/install-len.ps1` مباشرة من مستودع GitHub [`https://github.com/MohammedBoure/len.git`](https://github.com/MohammedBoure/len.git).

---

## 📦 التثبيت والتحديث التلقائي

تدير بيئة `myenv` أداة `len` بشكل تلقائي وذكي:

### 1. تشغيل سكريبت التثبيت والتحديث
```powershell
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\Documents\myenv\scripts\install-len.ps1"
```

### 2. آلية الفحص الذكي للإصدارات
- يقوم السكريبت بفحص أحدث Commit في مستودع GitHub البعيد.
- يفحص الحزمة المثبتة محلياً في بيئة Python.
- إذا كانت الأداة مثبتة ومحدثة على نفس الـ Commit، فلن يقوم بأي إجراء إضافي ويعود فوراً (No-op).
- إذا لم تكن مثبتة، أو كان هناك تحديث متوفر، أو كانت مثبتة بوضع Editable محلي، فيقوم بتثبيتها وترقيتها تلقائياً لأحدث نسخة.

### 3. الدمج مع الإعداد الشامل
يقوم سكريبت `scripts/setup-all.ps1` بتشغيل سكريبت التثبيت تلقائياً ضمن خطوات تهيئة البيئة.

## 💻 أمثلة وطريقة الاستخدام

### 1. الاستعراض الأساسي للشجرة
```bash
# فحص المجلد الحالي بالكامل
len

# فحص مجلد معين
len D:\my-project
len ./src
```

### 2. تحديد العمق (Depth)
```bash
# فحص المجلد الحالي حتى العمق 3
len 3

# فحص مجلد محدد حتى العمق 2
len ./src 2
```

### 3. نسخ الناتج للحافظة (`-c`)
```bash
# فحص حتى العمق 3 ونسخ الناتج مباشرة للحافظة
len 3 -c

# فحص مجلد محدد ونسخ الناتج
len ./src 2 -c
```

### 4. إدارة عناصر الحظر (Blocklist)
تُحفظ القواعد بشكل دائم في ملف `~/.lenconfig.json`:
```bash
# حظر ملفات ومجلدات معينة
len -f "*.log"
len -f secret.env
len -F node_modules
len -F ".git"

# إزالة عنصر من الحظر
len -rf "*.log"
len -rF node_modules

# استعراض قائمة الحظر الحالية
len -l
```

### 5. إحصائيات المشروع
```bash
# إظهار أسطر الكود وحجم الملفات
len -s

# إظهار إحصائيات متقدمة وشاملة للمشروع
len -s -e
```

## 🛠️ جدول خيارات الأوامر (CLI Reference)

| الخيار / المعامل | الاختصار | الوصف والدور |
|---|---|---|
| `[PATH]` | | مسار المجلد المراد فحصه (افتراضياً المجلد الحالي `.`) |
| `[DEPTH]` | `-d`, `--depth` | تحديد أقصى عمق للاستعراض (مثل `1`, `2`, `3`) |
| `-c` | `--copy` | نسخ شجرة المخرجات للحافظة تلقائياً |
| `-f <pattern>` | `--add-file` | إضافة نمط أو اسم ملف لقائمة الحظر |
| `-F <pattern>` | `--add-folder` | إضافة نمط أو اسم مجلد لقائمة الحظر |
| `-rf <pattern>` | `--remove-file` | إزالة ملف أو نمط من قائمة الحظر |
| `-rF <pattern>` | `--remove-folder` | إزالة مجلد أو نمط من قائمة الحظر |
| `-l` | `--list-blocked` | عرض قائمة العناصر المحظورة حالياً |
| `-s` | `--show-stats` | عرض عدد أسطر الكود وأحجام الملفات |
| `-e` | `--show-extended-stats` | عرض الإحصائيات الموسعة للمشروع |
| `-h` | `--help` | عرض قائمة المساعدة والتعليمات |
