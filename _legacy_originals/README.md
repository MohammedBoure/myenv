# Legacy & Original Backups Directory (`_legacy_originals/`)

This directory contains backup copies and historical configuration snapshots of dotfiles, window manager rules, themes, and scripts before centralization into the `myenv` environment.

## 📂 Contents & Categories

| Category / File | Description |
|---|---|
| `glazewm-before-*` | Historical GlazeWM YAML configs prior to workspace optimizations, zero gaps, and monitor bindings. |
| `yasb-*` / `styles-*` | Historical YASB bar configurations and CSS stylesheets before theme unification. |
| `profile.ps1.before-*` / `Microsoft.PowerShell_profile-*` | Historical PowerShell `$PROFILE` scripts before centralization. |
| `console-theme-before-*` | Historical console color scheme files and scripts. |
| `fastfetch-*` | Historical Fastfetch configuration and ASCII art. |
| `taskbar-*` | Registry backups for taskbar auto-hide configurations. |
| `glazewm-runtime-before-junction/` | Runtime backup directory for GlazeWM. |
| `yasb/` | Runtime backup directory for YASB. |
| `zebar/` | Runtime backup directory for Zebar. |
