# PowerShell Configuration Directory

This directory contains the central configuration, themes, formatting definitions, and interactive helper functions for PowerShell in the `myenv` environment.

---

## Files & Purpose

| File | Purpose |
|---|---|
| [`profile.ps1`](file:///C:/Users/moham/Documents/myenv/powershell/profile.ps1) | Single source of truth for PowerShell `$PROFILE`. Configures strict UTF-8 stream encoding (CodePage 65001), human-readable `size` table formatting via `FileSystem.format.ps1xml` with directory size support, PSReadLine Predictive IntelliSense (`HistoryAndPlugin`), `CompletionPredictor` module integration, default terminal editor (`$env:EDITOR = 'micro'`, `$env:VISUAL = 'micro'`, Git `core.editor`, and `m`/`mc` aliases), Arabic text reshaper (`Format-ArabicText` / `ar`), native GUI input dialog (`Get-ArabicInput`), AI CLI wrapper (`Invoke-ArabicCli` / `ask-ai`), development tools in `$env:Path`, environment variables, module loading, the `sudo` privilege escalation utility, and `np`/`nightpad`/`notepad` NightPad text editor functions. |
| [`FileSystem.format.ps1xml`](file:///C:/Users/moham/Documents/myenv/powershell/FileSystem.format.ps1xml) | Custom PowerShell table view format definition replacing the raw byte `Length` column with a human-readable `size` column (formatted as B, KB, MB, GB, TB) for `Get-ChildItem` and cached directory navigation. |
| [`midnight-aurora.ps1`](file:///C:/Users/moham/Documents/myenv/powershell/midnight-aurora.ps1) | Core interactive environment script. Sets up PSReadLine Predictive IntelliSense (ghost suggestions & list view via `F2`), interactive menu Tab completion (`MenuComplete`), history prefix search (`UpArrow`/`DownArrow`), word completion shortcuts (`Ctrl+F`, `Ctrl+RightArrow`), custom prompt with git branch detection, keybindings (`Ctrl+R`, `Ctrl+T`), folder tab auto-completion, and helper functions: `ls` (table directory lister with distinct column colors and `-s` / `-Size` sub-option for non-blocking in-place async folder size updates displaying incrementing numbers with dynamic `B`, `KB`, `MB`, `GB`, `TB` units), `cpf`, `cb`/`c`, `gc` (reads file raw, displays content, and copies directly to clipboard), `cf`/`cfile` (copies file or directory path as FileDropList to clipboard for pasting in Explorer/apps), `lensbridge-install`, `lensbridge-run`, `lensbridge-service`, `cd`/`chdir` (with human-readable auto-ls), `ll`, `la`, `gs`, `croot`, and `docs`. |
| [`cpf-ignore.txt`](file:///C:/Users/moham/Documents/myenv/powershell/cpf-ignore.txt) | Central ignore configuration file for `cpf` (defining ignored folders, files, and wildcard patterns like `.gitignore`). |
| [`console-theme.ps1`](file:///C:/Users/moham/Documents/myenv/powershell/console-theme.ps1) | Console window and terminal theming script applying Cascadia Code font (for Arabic glyph shaping), 32% transparency (68% opacity), true black background, and Midnight Aurora palette across both classic Windows Console (`conhost.exe`) and Windows 11 Windows Terminal (`wt.exe`). Includes persistent registry caching to prevent redundant writes on startup. |
| [`antigravity-switcher.ps1`](file:///C:/Users/moham/Documents/myenv/powershell/antigravity-switcher.ps1) | High-performance multi-account and isolated profile manager for Google Antigravity (`agys`, `agy1` through arbitrary `agyN`). Implements dynamic on-demand instance provisioning (`.gemini/instances/agy<N>`), full per-profile session/history/settings isolation, duplicate account detection, Win32 `AgyCredVault` C# P/Invoke helper, named Mutex concurrency locking (`Global\AgyCredentialMutex`), transparent argument and flag forwarding, stdin pipeline detection, `$global:LASTEXITCODE` propagation, and safe OAuth token refresh synchronization. |
| [`MyEnv.Helpers.cs`](file:///C:/Users/moham/Documents/myenv/powershell/MyEnv.Helpers.cs) | Consolidated C# source defining high-performance static helpers (`FolderSizeEngine` for folder size computations and `AgyCredVault` for Win32 Credential Manager access). |
| [`MyEnv.Helpers.dll`](file:///C:/Users/moham/Documents/myenv/powershell/MyEnv.Helpers.dll) | Precompiled static .NET assembly for `FolderSizeEngine` and `AgyCredVault`. Loaded at shell startup to eliminate runtime `Add-Type`/`csc.exe` JIT compilation delays. |
| [`winget-paths.cache`](file:///C:/Users/moham/Documents/myenv/powershell/winget-paths.cache) | Cached list of executable directories inside `AppData\Local\Microsoft\WinGet\Packages`. Automatically verified against directory timestamp and re-indexed on demand via `Update-WinGetPathCache`. |
