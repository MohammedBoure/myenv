# Tacky-Borders Configuration Directory (`tacky-borders/`)

Central configuration directory for **Tacky-Borders**, the high-performance native active window border utility for Windows 10 & 11.

## 📂 Files & Structure

| File | Purpose |
|---|---|
| [`config.yaml`](file:///C:/Users/moham/Documents/myenv/tacky-borders/config.yaml) | Main configuration file defining border dimensions, colors, rendering backend (V2 Direct3D), and square corner styles. |
| [`tacky-borders.log`](file:///C:/Users/moham/Documents/myenv/tacky-borders/tacky-borders.log) | Runtime log file generated by the tacky-borders background service. |

## 🔗 Directory Junction
Linked to `%USERPROFILE%\.config\tacky-borders` via NTFS directory junction managed by [`scripts/setup-all.ps1`](file:///C:/Users/moham/Documents/myenv/scripts/setup-all.ps1).
