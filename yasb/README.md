# YASB Configuration Directory (`yasb/`)

Yet Another Status Bar (YASB) configuration, widget definitions, and CSS styles.

## Files & Structure

| File | Purpose |
|---|---|
| [`config.yaml`](file:///C:/Users/moham/Documents/myenv/yasb/config.yaml) | YASB widgets configuration (GlazeWM workspaces, settings dropdown button, external microphone pronunciation button widget `translator_speak`, non-clickable translator text frame `translator`, system monitors, clock/date, audio, network). |
| [`styles.css`](file:///C:/Users/moham/Documents/myenv/yasb/styles.css) | Custom CSS styling implementing the Obsidian Sharp Dark aesthetic with 0px corner radius, transparent bar, external speak button, and translator text frame styles. |
| [`yasb.log`](file:///C:/Users/moham/Documents/myenv/yasb/yasb.log) | Runtime log output generated by the YASB process. |
